# loom

Renamed. This tool is now [`chip`](https://github.com/Tape-Out/chip).

![status](https://img.shields.io/badge/status-retired-lightgrey)

The package manager and assembler for the [Tape-Out](https://github.com/Tape-Out) IP
library lives at [`Tape-Out/chip`](https://github.com/Tape-Out/chip), where it continues
from our fork of [FuseSoC](https://github.com/olofk/fusesoc).

Nothing was ever published under this name. This repository is kept only so old links
do not dangle, and is archived.
